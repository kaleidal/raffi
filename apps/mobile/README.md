# Raffi Mobile + TV

Fresh Expo SDK 57 client for iOS, Android, and Android TV.

```bash
bun install
bun --filter @raffi/mobile start
bun --filter @raffi/mobile android
bun --filter @raffi/mobile android:tv
```

Expo Go supports the phone UI, direct playback, and QR pairing. Automatic mDNS discovery and Android TV require a development build.
